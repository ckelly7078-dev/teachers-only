# FM-17I: bounded tier-aware accuracy observations

This additive private backend adapter preserves FM-17D-H and the original editorial difficulty model. Use `Engine.from_bundle(root)` and `TierMarking.from_bundle(engine, root)` with the trusted cumulative private checkpoint. The private register is SHA-256-bound, version-bound and limited to individually specified one-mark accuracy criteria; unsupported criteria remain uncertain. No reference answers are exposed by capability. Original marking and official source routes remain separate.

`capability` preserves the existing mode and fingerprint gate and adds `coverage` (`full`, `partial`, or `none`). Full means every criterion has a bounded observation route, not that arbitrary learner methods can be assessed. New profiles list `checked_criteria` and `total_criteria`; `check_work` takes exactly those criterion IDs, using null for unsupported or absent evidence. Other valid representations must be translated by a trusted observer or remain uncertain. No method or reasoning marks are inferred from correct answers, no grouped award is split, and no grade, approval or release is granted. Existing Tier 3 dispatch is unchanged.

New comparisons use bounded rational strings, tagged exact radical sums, structured arrays and fixed labels; complete unordered collections permit mixed supported shapes, and selected equations and lines allow nonzero proportionality or equivalent parametrisations. Profile shape and question restrictions must be respected. The private reproduction and audit are not public and do not parse untrusted learner expressions. The adapter is not a student-script interpreter or a general proof checker. It does not connect the portal, change difficulty tiers, or supply empirical calibration.

Run `python -m unittest discover -s further_maths -p 'test_*.py'` from the code root. Private reproduction and runtime audit instructions are supplied with the cumulative private checkpoint. Unsupported items retain the original provisional marking context. See the private QA for exact coverage and limitations.
